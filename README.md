# 自然语言命令插件（neko_natural_command）

> 用 `/` + 自然语言触发命令。AI 在命令库里匹配，命中就执行；没命中可以自动学一条新命令存下来。

- 版本：`0.5.1`
- 作者：MENGYAOYUE
- 适用：N.E.K.O 插件运行时（SDK `>=0.1.0, <0.3.0`）
- 依赖：零第三方库

## 能做什么（实测可用）

- `/问候`、`/打开记事本`：触发命令库已有的命令
- `/打开B站搜索 原神`：参数化命令，搜索词自动填入
- `/cmdlist`：看当前所有命令
- `/插件`：看本机插件清单和可调用的能力入口
- `/su <密码>`：切管理员（部分命令需要）
- `/reloadcmd`：重载命令库

## 不太稳定 / 限制多的功能

- **深搜**：依赖外部搜索源和 LLM 多次调用，成功率不高，已弃用
- **自动学新命令**：依赖 LLM 输出合法 JSON，偶尔格式不对会失败
- **跨插件调用**：宿主 SDK 的跨插件接口在当前版本不可用（`ctx.plugins` 不存在），已做多形态兼容但未在生产环境验证
- **面板**：能看状态和命令库，但部分浏览器内核下可能显示异常

## 安装

1. 下载 `.neko-plugin` 包 → N.E.K.O 插件管理 → 导入
2. 在插件配置里设置 `admin_password`（不改的话插件禁用）
3. 启用插件

## 内置命令

| 命令 | 说明 |
|------|------|
| `/cmdlist` | 列出所有命令 |
| `/findcmd <关键词>` | 按关键词筛选 |
| `/插件` | 查看本机插件和能力入口 |
| `/调用 插件id:入口id 参数=值` | 直调其它插件能力 |
| `/delcmd <命令ID>` | 删除命令 |
| `/su <密码>` | 切管理员 |
| `/reloadcmd` | 重载命令库 |
| `/helpcmd` | 帮助 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `admin_password` | 无（必填） | 管理员密码，为空则插件禁用 |
| `auto_create` | `true` | 未匹配时是否自动创建新命令 |
| `auto_clean` | `true` | 启动时清理脏数据 |
| `default_permission` | `user` | 兜底权限 |
| `default_type` | `reply` | 新命令默认类型 |
| `llm_timeout` | `20` | LLM 超时（秒） |
| `shell_timeout` | `30` | shell 超时（秒） |
| `direct_call_permission` | `user` | `/调用` 的权限门槛 |
| `deep_search_max_pages` | `4` | 深搜页数上限（已弃用） |

## 命令类型

- `reply`：返回文本
- `shell`：执行系统命令
- `plugin`：调用其他插件的入口（当前 SDK 兼容性有限）

## 注意

- 管理员密码务必修改，不要留默认值
- AI 威胁审查是辅助手段，不能替代人工判断
- 不想要自动学命令就关 `auto_create`
